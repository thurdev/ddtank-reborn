Generated by `tools/i18n/images/gen-inventory.mjs` from an FFDec image export of all 119 client SWFs (every `ui/vietnam/swf/*.swf` + `Loading.swf`/`DDT_Loading.swf`/`1.png`,`2.png`,`3.png` — the last three are SWF data disguised with a .png extension) and a tesseract.js (`vie` language) OCR pass over every exported bitmap. ## Method

1. `export-all.sh` runs `ffdec-cli -export image` per SWF (resumable, skips already-exported dirs).
2. `ocr-scan.mjs` runs every exported PNG/JPG through tesseract.js `vie`, normalizing size (upscale <200px, downscale >900px) for speed/accuracy, writing one NDJSON row per image with the recognized text.
3. A row is kept here only if the OCR text contains a Vietnamese-specific diacritic character (ăâđêôơư + tone marks) — garbled OCR on photographic/painterly art (character portraits, map thumbnails) can still trip this heuristic; those are the main source of false positives in a full un-reviewed sweep like this one. Treat `ocrText` as a strong hint, not ground truth — open the image before using it.
4. `ptBrSuggestion`/`ptBrSource` come from (in order) the hand-curated top-priority caption map, an exact-phrase match against `language.txt` (VI) <-> `data/i18n/pt-BR/client-language.txt` (same key order), the MT cache from the DB/text localization batch, or a glossary.json substring substitution. `null` means nothing matched yet — translate in a batch before rendering.
