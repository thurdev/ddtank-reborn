# Security — DDTank Reborn

Achou vulnerabilidade? Reporte em privado pelo GitHub
(**Security › Report a vulnerability** neste repositório), nunca em issue/PR público.

- Inclua: versão/commit, passo a passo, impacto (exec remota? vazamento? cheat?).
- Correção crítica sai antes de divulgar.
- Nunca commite segredo. `.env.example` é o único lugar de exemplo.
- Flash/Ruffle: trate SWF como não-confiável; validação sempre no servidor.
