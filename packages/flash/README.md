# @ddt/flash — API do Flash Player sobre PixiJS

`flash.display`, `flash.events`, `flash.text`, `flash.net`... reimplementados em TypeScript sobre PixiJS v8,
pra o cliente transpilado (`apps/client`) rodar sem Flash/Ruffle.

O que existe e como completar API que falta: [docs/client-pixi/FLASH-RUNTIME.md](../../docs/client-pixi/FLASH-RUNTIME.md).
